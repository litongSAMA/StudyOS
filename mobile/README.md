# StudyOS Mobile

这是 StudyOS 的独立移动端前端。它复用现有后端 API，但拥有自己的移动端导航、触控布局、PWA 配置和构建产物；原 `web/` 前端不会被改动。

## 本地开发

先启动项目根目录下的后端，再启动移动端：

```bash
cd mobile
npm install
npm run dev
```

移动端默认地址：`http://127.0.0.1:5174/`

要在同一局域网的手机上预览，请运行：

```bash
npm run dev -- --host 0.0.0.0
```

然后在手机浏览器中打开终端显示的 `Network` 地址。校园网或访客网络若开启了设备隔离，需要换用允许局域网设备互访的网络。

## 生产构建

```bash
cd mobile
npm run build
```

构建产物位于 `mobile/dist/`。

## 专注与移动端入口

- 番茄钟计时卡内点「自定义时长」，可保存专注（1–240 分钟）、短休息（1–60 分钟）、长休息（1–120 分钟）及长休息间隔（1–12 个专注）。设置记忆在当前浏览器中。
- 修改设置不会重置正在进行或暂停的阶段；新时长在下一阶段或点击重置后使用。只有完成的专注会推进长休息轮次。
- 在应用内切换页面时，番茄钟继续保留，其他页面顶部可查看剩余时间并返回；刷新或关闭页面会结束当前计时。
- 底部固定「首页、资料库、录入、任务、全部功能」。全部功能按资料、计划、练习和设置分组并支持搜索；功能页顶部可切换同组页面。
- 任务卡片和复习块可以直接进入对应的专注计时，顶部返回按钮支持返回上页；直接打开链接时返回首页。
