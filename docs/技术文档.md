# StudyOS 技术文档

> 面向学生的个人学习管理智能体 · 校园生活赛道
> 本文档对应提交要求 **（2）技术文档**：系统架构图、模块说明、核心功能介绍、技术路线、部署方式、依赖环境和配置项说明。
> 每一节都给出**可核对的代码位置**，便于评审抽查。

## 1. 作品定位与价值

**一句话**：把「资料 — 任务 — 复习」三件事缝合成一个闭环的个人学习管家。

| 痛点（学生日常） | 现有做法 | StudyOS 的解法 |
| --- | --- | --- |
| 老师在群里说「下周五交大作业」，消息被刷走 | 截图存相册，考前才想起来 | 截图/文本/文件拖入即解析出 DDL，自动挂提前提醒（3 天/1 天/2 小时） |
| 课件 PPT、实验报告、PDF 塞满网盘/桌面 | 按文件名翻找，命名混乱 | 110 种格式自动抽取 + 自动打标签（课程/章节/难度/考试重点），统一归档、可检索 |
| 想找「上次讲傅里叶变换的那页 PPT」 | 逐个打开翻 | 中文分词全文检索（高亮摘录）+ 语义检索 + 混合检索（RRF 融合） |
| 期末 5 门考试挤在两周内，不知先复习哪科 | 凭感觉，往往来不及 | DDL 倒排 + 资料量 × 难度 × 考试重点 × 掌握程度加权，自动生成每日复习块与负载预警 |
| 错题散落在试卷和作业里 | 抄在本子上，不会再看 | 错题本归集 + 组合过滤 + 重练自评（连续答对 2 次自动「已掌握」） |
| 不知道「学没学会」 | 反复看书，自我感觉良好 | 笔记/资料一键 AI 出题抽背：选择题服务端判分、问答题回忆自评，留痕可复盘 |

**目标用户**：一学期 5~8 门课的本科生/研究生；资料以 PDF/PPT/截图/聊天文本形式散落。
**推广与复用潜力**：单机零配置即可用（无需注册、无网可用），课后可换课程库复用；
数据本地优先、导出即备份，适合在班级/社团内低成本试点。

## 2. 系统架构

### 2.1 分层架构

```
┌────────────────────────────────────────────────────────────────────────────┐
│  表现层  Web / Mobile 双端同源（React 18 + TypeScript + Tailwind v4 + PWA）    │
│  页面：资料 · 周课表 · 任务DDL · 复习计划 · 笔记 · 错题本 · 自测 · 专注 ·     │
│        进度预测 · 清单模版 · 助手 · 学习报告 · 设置                           │
│  能力：Service Worker 离线缓存 + Web Push 推送 + 响应式（手机端窄屏无溢出）    │
└───────────────────────────┬────────────────────────────────────────────────┘
                            │  HTTP/JSON（Bearer 会话令牌；同源校验）
┌───────────────────────────▼────────────────────────────────────────────────┐
│  接口层  FastAPI（app/main.py）                                              │
│  · 登录收口中间件 login_guard（登录保护开启时统一 401）                       │
│  · 同源校验中间件 csrf_origin_guard（所有写操作校验 Origin）                  │
│  · 17 个路由模块（routers/）+ 交互式文档 /docs                              │
└───────────────────────────┬────────────────────────────────────────────────┘
┌───────────────────────────▼────────────────────────────────────────────────┐
│  领域层（纯函数引擎，确定性可测，与 HTTP 解耦）                                │
│  抽取 Agent（agent/）       中文时间归一化 · 事件级拆分 · 规则/LLM 双通道      │
│  格式与抽取（ingest/）      110 种格式登记 · 内容嗅探 · 扫描件 OCR · 有界解压  │
│  间隔重复（spacedrep.py）   SM-2 变体：四档评分 → 掌握度 → 间隔阶梯           │
│  出题引擎（quizgen.py）     结构化出题 + 离线挖空/定义/回忆题降级             │
│  进度预测（forecast.py）    DDL 倒排 + 顺序仿真 + 负载告警                    │
│  课表解析（courseimport*.py）八类来源 → 统一字符串网格 → 同一套解析           │
│  检索（searchutil/semantic/materialquery）FTS5 + 向量 + 标签 SQL 下推         │
│  导出（exports/）           iCal(RFC5545) · CSV(BOM) · Markdown + 增量基线    │
└───────────────────────────┬────────────────────────────────────────────────┘
┌───────────────────────────▼────────────────────────────────────────────────┐
│  数据层  本地优先（app/config.py::data_dir，可用 DATA_DIR 改到任意私有路径）   │
│  SQLite（SQLAlchemy 2.0 + FTS5 全文索引 + jieba 分词 + 语义向量缓存表）        │
│  附件目录 data/files（上传文件按 UUID 落盘，只允许在此目录内读写/删除）        │
└────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 核心链路数据流（端到端闭环）

```
   输入                 处理                      输出                兜底
┌──────────┐   ┌────────────────────┐   ┌──────────────────┐   ┌──────────────┐
│ 粘贴文本 │   │ 抽取 Agent         │   │ 结构化资料       │   │ 未配置 Key   │
│ 拖拽文件 ├──▶│ ·内容嗅探(110格式) ├──▶│ 课程/章节/难度/  │──▶│ → 离线规则    │
│ 上传截图 │   │ ·文本抽取(OCR)     │   │ 类型/考试重点/   │   │   引擎        │
│ 课表导出 │   │ ·时间归一化        │   │ 关键词标签       │   │ 无 OCR 依赖  │
└──────────┘   │ ·事件级任务拆分    │   │ DDL 任务+提醒点  │   │ → 明确指引    │
               └────────────────────┘   └────────┬─────────┘   └──────────────┘
                                                 │
        ┌────────────────────────────────────────┼─────────────────────────────┐
        ▼                    ▼                   ▼                             ▼
 ┌─────────────┐   ┌─────────────────┐  ┌────────────────┐          ┌────────────────┐
 │ 检索        │   │ 笔记提炼        │  │ 复习计划生成    │          │ 提醒           │
 │ 全文/语义/  │   │ 重点·考点双模式 │  │ DDL倒排×难度×  │          │ Web Push 真推送│
 │ 混合 + 标签 │   │ LLM/离线降级    │  │ 考点×掌握度    │          │ + 站内角标     │
 │ SQL 下推    │   │ 可核对原文      │  │ 间隔复习优先   │          │ + iCal 兜底    │
 └─────────────┘   └────────┬────────┘  └───────┬────────┘          └────────────────┘
                            │                   │
                            ▼                   ▼
                    ┌──────────────┐   ┌──────────────────┐   ┌──────────────────┐
                    │ AI 自测抽背  │   │ 番茄钟专注计时    │   │ 错题归集 → 重练  │
                    │ 选择判分 +   │   │ 可挂 DDL/课程/    │   │ 连续答对 2 次    │
                    │ 问答自评     │   │ 复习块 → 完成评分 │   │ → 已掌握         │
                    └──────┬───────┘   └────────┬─────────┘   └────────┬─────────┘
                           └────────────┬───────┴──────────────────────┘
                                        ▼
                         ┌──────────────────────────────┐
                         │ 多格式导出（iCal/CSV/MD）     │
                         │ 增量导出 + 导出历史 + 备份 zip│
                         └──────────────────────────────┘
```

**关键设计**：**入库时顺带完成三件事**——存原文、打标签、抽 DDL。一次操作，整条链路的输入就齐了；
检索到的资料一键提炼成笔记喂给复习计划，做错的题归集重练，笔记一键出题自测，
复习块一键开专注并在完成时给资料评分回喂间隔重复——形成「输入—消化—检测—纠错」闭环。

## 3. 模块说明

## 4. 核心功能说明

| # | 功能 | 关键行为 | 代码位置 |
| --- | --- | --- | --- |
| 1 | **资料入库（多通道）** | 粘贴/拖拽/上传截图/上传文件；**110 种格式 / 12 分组**全部按**内容**嗅探（改名成 `.ppt` 的 PPTX、无扩展名导出、伪装成 `.txt` 的网页都能纠正）；中文编码阶梯（UTF-8/GB18030/Big5/Shift-JIS/EUC-KR）；扫描版 PDF 自动栅格化 OCR；压缩包有界展开、嵌套只展开一层 | `app/ingest/`、`routers/materials.py`、`agent/extractor.py` |
| 2 | **课表导入（八类来源）** | 教务 Excel（.xlsx/.xls/.xlsm）/CSV/TSV/ODS/PDF/网页/Word/.ics/.json/截图 → 统一「行=节次、列=星期」网格 → 同一套解析；预览 → 勾选 → 确认导入；同名课程自动合并；开学日期自动推算 | `app/courseimport*.py`、`app/ingest/ocrgrid.py`、`routers/courses.py` |
| 3 | **结构化标签** | 课程 · 学期 · 类型 · 章节（独立字段）· 难度（简单/中等/困难）· 考试重点 + 关键词自动打标，人工可改 | `agent/`、`materialquery.py` |

## 5. 技术路线

### 5.1 选型与理由

| 层 | 选型 | 理由 |
| --- | --- | --- |
| 后端 | **FastAPI + Pydantic v2** | 类型化 Schema 自动生成 OpenAPI（`/docs` 即接口文档）；同一进程托管前端构建产物，**单端口部署**，评审零配置 |
| 数据 | **SQLite + SQLAlchemy 2.0 + FTS5** | 单机零运维、事务可靠；FTS5 提供 bm25 排序与高亮；数据就是一个文件，**导出/备份/搬机成本极低** |
| 中文检索 | **jieba 分词 + FTS5 + 离线 TF-IDF 向量** | 中文分词质量决定检索命中率；未配置 Embedding 时用内置 TF-IDF，**断网可用** |
| 前端 | **React + TypeScript + Tailwind v4 + Vite + PWA** | 组件化 + 类型安全；PWA 提供离线外壳与 Web Push；双端（Web/Mobile）共享业务逻辑与测试 |
| 文档解析 | **PyMuPDF / python-docx / python-pptx / openpyxl / xlrd / 标准库** | 覆盖学生最常见的课件与教务导出格式；能自己写就不引重型依赖 |
| OCR | **RapidOCR（ONNXRuntime）离线模型** | 不联网、不上传图片，截图与课表照片可识别；**可选依赖**，缺失时功能降级并给指引 |
| AI | **OpenAI 兼容协议（DeepSeek/OpenAI/Ollama…）** | 一套适配层兼容主流服务商与本地模型，使用者可自由切换；**未配置时全功能离线可用** |
| 推送 | **Web Push（VAPID）+ Service Worker** | 页面关闭也能收到提醒；不可用的环境回落 iCal 导入系统日历 |
| 测试 | **pytest（后端 657 项）+ Node 内置 test runner（Web 103 / Mobile 99）** | 纯函数引擎 + 临时库隔离，测试快、确定、可离线复现 |

### 5.2 双引擎降级策略（贯穿全系统的健壮性主线）

```
        有 Key / 有模型                          无 Key / 调用失败 / 断网
LLM 通道 ─────────────────────▶ 结构化结果      离线通道 ──────────────▶ 规则结果
· 抽取（时间/标签/事件拆分）                      · 中文时间正则 + 学期锚点换算
· 笔记提炼（重点/考点）                           · 抽取式摘要（词频×位置×考点信号词）
· 错题字段补全（不编造答案）                      · 只填能确定的，其余留空
· 自测出题（选择+问答+解析）                      · 挖空选择 + 定义题 + 要点回忆
· 课表图片兜底抽取                                · OCR 坐标网格重建（双通道互为兜底）
```

**原则**：任何一处外部依赖不可用，功能都要能用，且界面与接口字段（`engine`/`ai_assisted`）
**如实标注**本次结果来自哪条通道——不谎称使用了远程模型。所有降级路径都有回归用例。

### 5.3 关键技术点

1. **格式按内容判定**：扩展名不可信，用魔数 + 容器内部结构（OOXML/ODF/EPUB 看 ZIP 内部结构、
   `.doc/.xls/.ppt` 看 OLE2 流名、图片/音视频看文件头）；不符时按内容解析并在回包 `mismatch` 提示。
2. **统一网格解析**：八类课表来源先还原成「行=节次、列=星期」字符串网格，再走同一套解析——
   新增来源不需要重写解析逻辑（已实测南京理工大学教务系统版式的六处坑）。
3. **过滤下推 SQL**：标签存 JSON 列，用 `json_each` 做 EXISTS 匹配；分页与计数都在过滤之后，
   避免「先取一页再内存筛」导致大库丢结果（`X-Total-Count` 给出真实总数）。
4. **时间口径统一**：库内 naive UTC 存储、API/快照一律带 `Z`、展示按设备本地时区；
   课表时段按「本地墙上时间」语义存储（不随时区换算）。
5. **幂等与事务**：写操作支持 `Idempotency-Key`（同键同内容读回执、同键不同内容 409）；
   提案「预览 → 确认 → 撤销」三态，执行前校验数据是否变化（否则 409 重新生成）。
6. **有界与防炸**：上传按字节上限流式落盘；压缩包按「条目数 × 单条体积 × 解压总量」三重上限展开；
   图片 OCR 前校验像素（单边 ≤12000px、总像素 ≤5000 万）；扫描 PDF 的 OCR 有页数上限且临时文件必清理。
7. **安全默认值**：密码/令牌只存哈希、密钥只回掩码、写操作校验同源、敏感披露限本机、
   出站请求拒绝内网/云元数据地址（SSRF）。
8. **出站请求的代理边界**：本机与内网端点（本地 Ollama、局域网对端、局域网分享链接）
   显式 `trust_env=False` 直连，公网服务沿用用户代理设置——用户机器上的代理不会破坏本机功能
   （`app/netutil.py`，5 处调用点 + 13 项回归）。
