## 1. 服务端幂等、跨批次去重与跨设备队列

- Agent 入库、提案执行和撤销要求 `Idempotency-Key`。同账号同键只提交一次；同键不同内容返回 409。业务数据、操作记录、索引和回执在同一 SQLite 事务内提交。
- 重启、并发重试与响应丢失读取原回执。新键的重复批次按规范化标题、课程、截止时刻或全文/附件 SHA-256 确定性匹配，返回复用对象；不进行模糊语义合并。
- Web/Mobile 原写请求与队列改为 `localStorage` 持久保存，可跨浏览器重启恢复。写入前检查存储是否成功；账号归属不符会阻止重试，跨标签写操作使用 Web Locks 串行提交。
- 队列支持草稿、已确认入库批次、导入导出、原键发送、回执查询和刷新恢复。导入整批校验、限制 100 条/2 MB，冲突或存储失败不产生假成功提示。导出提供文件及可复制 JSON 文本。
- 同一账号、同一原请求键在两台独立设备应用时，新任务/资料使用稳定 UUID；随后同步能收敛。同步携带最近 1000 条有效入库回执，并用 UUID 映射本机整数 ID，避免拿另一设备的 ID 重试。
- 同步回执内容冲突时，整批业务合并回滚；附件写入失败清理新文件并保留原文件。

**使用边界：** 跨设备队列目前通过 JSON 手动迁移与确认发送，不自动后台发送。仅纯文本入库批次和草稿可迁移，附件须在目标设备重新上传；提案和撤销依赖本机状态，须重新预览。两端需升级且使用同名账号与配对同步令牌。旧 CRUD 写操作没有全部改为幂等接口；独立设备以不同请求键录入近似内容，不保证在同步前自动合并。

## 2. 延期识别与考试关联重排

- 延期、推迟、提前和「改为」类通知匹配未完成原任务；多项匹配先选择，不把通知另建成任务。只解析变更标记后的新日期，保留原任务来源、备注、资料及提醒提前量。
- 模糊日期、过去时间和时区歧义拒绝执行；缺少时刻时沿用原任务本地时刻并提示核对。确认后截止日期和旧发送记录一起更新。
- 考试日期变更后，返回受影响的复习计划及「关联重排」入口。继续生成新预览，用户另行确认才修改计划；延期重试仍返回相同关联建议。
- 重排保留实际投入时长，结合掌握度、到期复习、考试顺序、课表和其它计划负载。容量不足明确提示且禁止执行，不虚构专注记录或评分。
- 操作撤销检查后续编辑、提醒、学习进度及引用；已被专注记录使用的新任务或计划不能直接删除。撤销与删除墓碑同步使用正式应用的实体名称。

计划目前按日分配小时，尚未把复习块排入具体日历空闲时段。已发送通知不能收回。

## 3. 混合检索与多轮跨模块对话

- 助手联动资料片段、未完成任务、到期复习、计划与真实专注，提供对应模块及绑定任务的专注入口。
- 检索复用 FTS、同义词/向量式召回与混合排序。未配置外部 Embedding 时使用本地语义降级路径，不宣称已调用远程模型。
- 对话持久保存、按账号读取，支持历史恢复、课程/任务/计划选择及「再详细」等追问。每轮请求 ID 幂等，版本比较避免两端同时覆盖同一会话。
- 配置 LLM 后可使用有限历史与检索证据生成解释；失败回落离线助手。资料内容作为证据处理，模型输出不能直接提供可执行动作；修改仍由服务器生成、保存并核验提案。
- 对话保留最近 20 轮；同一服务的 Web/Mobile 可恢复历史。不同独立服务器之间尚未同步对话记录。

## 运行与接口

已恢复原启动入口。在项目根目录执行 `./scripts/start.sh`，默认应用地址 `http://127.0.0.1:8800`，托管 `web/dist`。也可在 `backend` 使用 `.venv/bin/uvicorn app.api.main:app --host 127.0.0.1 --port 8800`。生产环境继续使用正式配置的数据与附件目录。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/agent/capabilities` | 能力、账号主体与设备握手 |
| POST | `/api/agent/apply` | 幂等入库 |
| GET | `/api/agent/receipts/{key}` | 本机或同步回执查询 |
| GET | `/api/agent/operations` | 当前主体操作记录 |
| GET | `/api/agent/context` | 学习上下文 |
| GET | `/api/agent/conversations`、`/api/agent/conversations/{id}` | 历史会话 |
| POST | `/api/agent/chat` | 多轮对话与提案 |
| POST | `/api/agent/deadline/preview` | 截止日期变更预览 |
| POST | `/api/agent/review/generate`、`/api/agent/review/replan` | 复习生成与重排预览 |
| POST | `/api/agent/plans/{id}/apply` | 确认提案，需幂等键 |
| POST | `/api/agent/operations/{id}/undo` | 撤销，需幂等键 |

本机账号恢复入口：`cd backend && .venv/bin/python -m app.authadmin -h`。修改密码会撤销旧会话。独立标准库 `agent_core.server` 保留作隔离调试入口，正式应用使用 FastAPI 适配与原鉴权。

## 后续完善建议

1. 队列自动恢复与冲突处理：联网后明确提示待提交批次，加入设备间冲突比对；为回执、审计和去重建立索引与保留策略。
2. 跨设备对话同步与证据定位：同步会话版本、支持跳到原文具体片段，对低把握任务匹配增加明确的选择流程。
3. 日历时段规划：结合可用时段、任务依赖与考试变动，生成可确认的连带重排；学习进度明显变化时提出建议。
4. 并发学习记录合并：自测逐题和复习评分按事件合并，减少整行「最后更新时间优先」对并发编辑的覆盖。
5. 真实设备与服务商联调：浏览器推送端到端送达、模型证据质量评估和联系人验证；继续压缩 PPT 预览依赖。
