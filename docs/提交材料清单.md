## 1. 可运行作品（要求 1）

### 1.1 最快的验证路径：一键启动 + 演示数据

```bat
:: Windows：双击 scripts\start.bat（自动建 venv、装依赖、起服务、开浏览器）
start.bat
```
```bash
# macOS / Linux
./scripts/start.sh -d  # 后台常驻；前台运行去掉 -d
```

访问 **http://127.0.0.1:8800** 。首次启动会在 `backend\.venv` 自动创建虚拟环境并按
`backend/requirements.txt`（**逐项 `==` 锁定版本**）安装依赖，无需手工 pip。

灌入演示数据（合成数据，可随时删除；评审/答辩前重置演示环境用）：

```bat
cd backend
.venv\Scripts\python.exe scripts\seed.py --reset     :: Windows
```
```bash
cd backend && .venv/bin/python scripts/seed.py --reset   # macOS / Linux
```

脚本会先打印后端连通性与当前数据量，再清空并灌入 4 门课程 / 13 条资料与 DDL / 复习计划 /
间隔重复评分 / 4 道错题（含 1 道已演示「答对两次 → 已掌握」）。其他参数：

| 参数 | 用途 |
| --- | --- |
| `--check` | 只检查后端可达性与当前数据量，**不写任何数据** |
| `--dry-run` | 只打印将要执行的动作，不写数据（离线演示流程） |
| `--base http://127.0.0.1:8800/api` | 指定后端地址（默认 8800，也可用环境变量 `STUDYOS_BASE`） |
| `--reset` | **破坏性**：先清空已有学习数据再灌演示数据 |

### 1.2 登录与演示模式（本项目默认无需登录）

- **演示模式（默认，推荐评审直接用）**：本地账号体系存在但「登录保护」**默认关闭**——
  打开 http://127.0.0.1:8800 即可直接使用全部功能，**无需注册、无需测试账号**。
  这是刻意的设计：单机作品不该用登录挡住第一次体验。
- **如需演示登录保护**（评委想验证账号能力时）：界面右上角进入登录/注册 → 注册任意用户名
  （如 `demo` / 密码 `studyos2026`）→ 设置页打开「登录保护」。开启后除公开分享、健康检查、
  认证接口外的所有 API 与页面都要求登录；忘记密码用命令行恢复
  （`cd backend && .venv\Scripts\python.exe -m app.authadmin reset-password demo`，兼容写法 `-m app.api.authadmin`）。
- **数据边界**：账号只存本机、**不进同步快照也不进备份**；全部账号共享同一份本机学习数据
  （登录是「本机访问锁」，不是多租户隔离）——这一点在 README 与合规说明中都如实标注。

### 1.3 可访问链接与可执行包

| 形态 | 说明 |
| --- | --- |
| 本机访问链接 | `http://127.0.0.1:8800`（后端同时托管前端构建产物 `web/dist`，单端口即用） |
| 局域网访问 | 启动脚本会打印 `http://<局域网IP>:8800`，同一 Wi-Fi 下的手机/平板可直接打开（手机端界面 `mobile/dist` 可用 `WEB_DIST` 指定） |
| 交互式接口文档 | `http://127.0.0.1:8800/docs`（自动生成的 OpenAPI 调试页） |
| 可执行包 | `release/StudyOS-Windows-x64.zip`（免安装 Windows 包，校验值见 `release/SHA256SUMS.txt`）；源码形态即整个项目目录 |
| 离线可用性 | 未配置任何大模型 Key 时，抽取/提炼/出题/语义检索全部走**内置离线引擎**，无网也能演示全流程 |

## 6. 本轮为「可运行作品」修掉的实际缺陷（自检发现）

| # | 问题 | 影响 | 处理 |
| --- | --- | --- | --- |
| 1 | 前端资料页调用的 `POST /api/materials/batch/{delete,tags,course,fields}` 后端**缺失** | 界面上的批量删除/批量改标签/批量换课程/批量改归档字段在实际运行中会失败 | 已实现四条接口（同一事务、附件/FTS/语义缓存/复习状态一并清理、未知 id 计入 `missing`），并补 18 项回归 `tests/test_material_batch.py` |
| 2 | httpx 默认继承系统代理，**本机/内网请求被代理截走** | 装过代理的机器上本地 Ollama 连不上，AI 连通性测试报「服务返回 503」而不是「无法连接」；局域网同步/分享抓取同样受影响 | 新增 `app/netutil.py`：loopback / 私有网段 / `.local` 一律直连，公网仍走用户代理；接入 LLM、embedding、连通性测试、同步、分享抓取 5 处，补 13 项回归 |
| 3 | `python -m venv` 在部分 Python 构建上不装 pip（ensurepip 失败） | 新机器双击 `scripts\start.bat` 会卡在「No module named pip」 | `scripts/start.bat` 增加 pip 自检与自举（用系统 pip `--python` 注入），失败才提示手工修复 |
| 4 | README 提到的 Windows 测试入口 `scripts\test.bat` 不存在 | Windows 用户无法按文档跑测试 | 新增 `backend/scripts/test.bat`（自动建 venv/装依赖/透传 pytest 参数） |
| 5 | 测试临时目录不可配置、`mkdtemp` 目录在受限环境无法建库/删文件；普通 Windows 账户无创建符号链接权限 | 受限环境/CI 下成套用例误报失败 | `tests/conftest.py` 与 agent 用例支持 `STUDYOS_TEST_TMP` 并改用 `makedirs` 建目录（`tests/tmphelper.py`）；软链接用例显式 skip 并说明原因 |
| 6 | 演示脚本硬编码 8800 端口、不能重置、缺参数 | 评审换端口/端口冲突时无法灌数据；重置演示环境要手工删数据 | `scripts/seed.py` 增加 `--base/--reset/--check/--dry-run`，输出连通性与灌入前后数据量复核 |

复跑验证（本机 Python 3.14 + 依赖锁定版本）：

```bat
cd backend
.venv\Scripts\python.exe -m pytest tests -q
```

**实测结果**：`727 passed, 1 skipped, 0 failed`（33 秒）。
跳过项是「软链接逃逸」用例——当前账户没有创建符号链接的 Windows 权限（WinError 1314），
用例显式 `skipTest` 并打印原因，而不是伪装成通过。

> 说明：`docs/用例集.md` 的「自动化依据」列在此命令下逐条可复现；测试使用临时数据库，
> **不读写** `backend/data/studyos.db`。受限环境可用 `STUDYOS_TEST_TMP` 指定临时库根目录。
