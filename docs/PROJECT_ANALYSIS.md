# StudyOS — 学生个人学习管理智能体 · 项目分析

> 赛道：校园生活 · 面向学生个人用户 · 作品形态不限（Web / 小程序 / 桌面端 / 机器人）

---

## 1. 赛道解读与机会点

**一句话定位**：把「资料 — 任务 — 复习」三件事缝合成一个闭环的个人学习管家。

学生已有的工具现状：

| 工具 | 能做什么 | 缺什么 |
|---|---|---|
| 滴答清单 / Todoist | DDL 记录与提醒 | 与课程资料完全割裂，无归档、无复习 |
| Notion / 飞书多维表格 | 资料归档、手动建库 | 录入成本高（手动打标签）、提醒弱 |
| GoodNotes / MarginNote | 资料阅读批注 | 无 DDL、无计划 |
| 教务系统 / 课程群 | DDL 的真实来源 | 消息沉底、分散在多个群、不可检索 |

**机会点**：现有工具都在做「一半」，没有人把「资料入库 → 标签 → 检索 → 提醒 → 复习」打通。而打通之后的闭环价值远超各部分之和——复习计划可以直接挂在 DDL 倒排上，检索到的资料可以一键生成复习清单。

**差异化打法（评审讲故事的主线）**：
1. 自动化降成本：截图/文本/文件名一键入库，自动抽 DDL 和标签——学生不用当「档案管理员」。
2. 闭环增值：DDL 驱动复习计划，资料量决定复习分配。
3. 数据主权：本地优先存储 + 随时导出带走，回应「长期可用性」和「数据安全」两个评审点。
4. **AI 参与学习全链路（自测抽背）**：AI 不止在入库/提炼环节——笔记一键出题抽背，
   选择题服务端自动判分、问答题回忆自评，把「资料 → 笔记 → 自测」打成检测闭环，
   这是多数笔记/清单类作品没有的「AI 出题」能力。

## 2. 目标用户与核心痛点

用户画像：大学本科生/研究生，一学期 5–8 门课，DDL 来源分散（课程群、教务系统、口头通知），资料以 PDF/PPT/截图/聊天文本形式散落。

四个高频痛点（对应四条典型任务）：

| # | 痛点场景 | 现有做法 | 我们的解法 |
|---|---|---|---|
| 1 | 老师在群里说「下周五交大作业」，消息很快被刷走 | 截图存相册，考前才想起来 | 截图/文本拖入即解析出 DDL，自动挂提醒 |
| 2 | 课件 PPT、实验报告、老师给的 PDF 塞满网盘/桌面 | 按文件名翻找，命名混乱 | 自动打标签（课程/学期/类型/关键词），统一归档 |
| 3 | 想找「上次讲傅里叶变换的那页 PPT」 | 逐个打开翻 | 标签过滤 + 全文检索 + 语义检索 |
| 4 | 期末 5 门考试挤在两周内，不知道先复习哪科 | 凭感觉，往往来不及 | 按 DDL 倒排 + 资料量 + 难度权重自动生成复习清单 |

## 3. 核心业务流程（硬性要求 ①）

```
资料入库 ──▶ 结构化标签 ──▶ 检索 ──▶ 笔记提炼 ──▶ 提醒 ──▶ 复习清单生成 ──▶ 多格式导出
   │             │              │          │            │
 粘贴文本      自动标签      关键词/标签  重点/考点    DDL 倒计时
 拖拽文件      手动修正       全文/语义    结构化笔记   提前 N 天推送
 上传截图      （人工可改）   （可选增强）  可编辑可导出  复习计划提醒
   │             │              │          │            │
   └── 解析时同时提取 DDL 与标签（自动化能力主线贯穿全程）──┘

错题归集 ──▶ 自动分类归档（章节/难度规则抽取） ──▶ 组合过滤/检索 ──▶ 重练自评
                └── 连续答对 2 次 → 已掌握；答错清零回退（掌握判定闭环）

笔记/资料 ──▶ AI 自测抽背（选择题自动判分 + 问答题回忆自评）──▶ 得分与错题留痕
                └── 抽背不过的题 → 回笔记复习 → 再测（输入—消化—检测闭环）
```

关键设计：**入库时顺带完成三件事**——存原文、打标签、抽 DDL。一次操作，整条链路的输入就齐了；
检索到的资料再一键**提炼**成重点/考点笔记，直接喂给复习清单；做错的题**归集**进错题本，
重练到掌握，与复习计划形成「输入—消化—纠错」闭环；笔记一键**出题自测**，
选择题自动判分、问答题抽背自评，「学没学会」当场可测。

## 4. 功能模块拆解

### 4.1 资料入库（多通道）
- 拖拽/粘贴：PDF、PPT、Word、图片、纯文本
- 聊天式录入：像发消息一样写一句「操作系统作业，下周三交，附件是实验三报告」→ 拆出任务 + 资料
- 批量导入：整个课程文件夹一次倒入，按文件名规律分课程

### 4.2 结构化标签体系
- 系统标签：课程、学期、资料类型（课件/作业/实验/试卷/笔记/讲义）
- **归档字段（已实现）**：
  - **章节**：独立字段（`第N章`/`Chapter N` 自动抽取 + 章节名），支持过滤（SQL LIKE 下推）、
    章节聚合下拉（按章节号自然排序）、全文检索命中
  - **难度**：简单/中等/困难（关键词自动判定，可手动修正），参与复习时长加权
  - **考试重点**：老师强调的考点/必考/常考内容独立标记（专用筛选开关 + 徽章），
    复习计划优先分配时间
- 自动标签：关键词抽取（LLM）、近邻资料标签继承（同课程同主题的资料自动聚簇）
- 用户标签：自定义，支持手动修正（自动结果永远可改）

### 4.3 检索
- 组合过滤：课程 × 类型 × 多标签（任一/全部）；**过滤全部下推 SQL**——标签存 JSON 列，
  用 SQLite `json_each()` 展开做 EXISTS 精确匹配，计数/排序/分页都在过滤之后，
  资料量大时不会出现「先取一页再筛标签」导致的结果缺失（`X-Total-Count` 给出真实总数）
- 标签云：SQL `GROUP BY` 全库聚合（带资料数），不是「当前页出现过的标签」
- 全文检索：PDF/PPT 抽取的文本 + OCR 文本入库建索引；FTS5 命中与过滤条件在同一条 SQL 内 JOIN
- 语义检索（增强项）：输入「那个讲死锁的例子」，向量召回相关段落

### 4.4 DDL 管理与提醒
- 时间抽取归一化：支持「下周五」「11.30」「第12周周三」「今晚 24:00」「三天后」等表达
- 提醒策略：默认提前 3 天 + 1 天 + 截止前 2 小时，可自定义；截止后未完成进入「逾期」看板
- 通知渠道（已实现）：
  - **Web Push（真推送）**：浏览器 Service Worker push 订阅 + 后端 VAPID 签名（pywebpush）
    经浏览器推送服务送达 `push` 事件——**页面关闭也能收到**；后端每分钟检查提醒点，
    送达记录落库去重（重启不重发，新订阅静默基线不轰炸历史），失效订阅（404/410）自动清理
  - **iCal 兜底**：导出 .ics（VALARM 提前提醒）导入手机/电脑系统日历，覆盖手机端与不支持
    Web Push 的环境（如非 HTTPS 局域网访问）
  - 站内角标：侧边栏铃铛显示 24 小时内到期任务（页面内轮询，不依赖推送）

### 4.5 复习清单生成（掌握程度加权 + 间隔重复，已升级）
- 输入：考试/大作业 DDL + 该课程资料量 + 难度权重 + 考试重点标记 + **每份资料的掌握程度（0~1）**
- 算法：按 DDL 倒排生成每日复习块（如「11.25 复习操作系统：进程调度 + 死锁，对应资料 3 份」），每块附可直接打开的对应资料；每份资料的学习时长 = 基础时长 × 难度权重（简单 0.8 / 中等 1.0 / 困难 1.5）× 考试重点 1.3 × **掌握系数（未掌握 1.6 → 已掌握 1.0）**，考点与困难资料排在复习列表前面
- **间隔重复（SM-2 变体）**：复习后四档评分（忘了/吃力/正常/轻松）→ 掌握度实时更新、间隔按 1→2→4→7→14→30 天阶梯拉长、again 遗忘回退；复习页有「今日到期复习」队列与掌握度看板；计划生成时**到期的间隔复习排在新学前面**（检索练习先行），**首次学习的资料自动预排 1/3/7 天检查点**，已掌握的资料不再排初次学习、只按间隔维持
- 可导出为任务提醒（iCal/CSV/Markdown，复习块带掌握度与到期复习标记），复习计划本身也进提醒系统

### 4.6 多格式导出（硬性要求 ③）
- **iCal**（RFC 5545）：DDL 任务与复习计划，带 VALARM 提醒，UID 稳定保证重复导入不重复；
  **资料目录同样是真 iCal**——每条资料一个全天事件（锚定入库日期，形成「资料收集时间线」），
  元数据进 DESCRIPTION，不再是 Markdown 内容兜底
- **CSV**：UTF-8 BOM 编码（Excel 打开中文不乱码），DDL 表 + 资料目录表
- **Markdown**：人可读的复习清单（`- [ ]` 勾选格式）与资料索引，可进 Git/打印
- **增量导出（已实现）**：`export_records` 记录每次导出的时间窗口（since→until）与条数，
  既是可查历史，也是增量基线；`?incremental=true` 只导出自上次「同类型 × 同格式」导出以来
  新增/修改的条目（`updated_at` 回落 `created_at`），首次无基线自动退化为全量，
  空增量不写记录（基线不前移）；`?since=<ISO>` 可显式指定起点，清空历史 = 重置基线

### 4.7 AI 智能笔记提炼（已实现）

「资料入库 → 检索到 → 提炼成笔记 → 复习」的最后一块拼图：当前系统只能**抽取**（结构化标签/DDL），
本模块把资料全文**提炼**成可直接复习的笔记。

- **两种模式**：
  - **重点笔记**（keypoints）：核心概念、定义、原理、公式、结论与方法，去掉铺垫与口水话；
  - **考点笔记**（exam）：必考/常考/高频考点、易错易混淆点、常见考法——与资料归档的
    「考试重点」字段呼应，复习计划的考点加权资料点一下即得考点清单
- **双引擎 + 离线兜底**（与抽取 Agent 同一原则）：
  - LLM 通道：结构化 JSON 输出 `{title, summary, points[{point, importance}]}`，
    重要度 high/medium/low，忠实原文不编造；
  - 离线规则通道（抽取式摘要）：句子按「词频覆盖（jieba + n-gram 与语义检索同一套分词）
    × 位置权重（首句主题句/末句总结）× 重点/考点信号词加成」打分，高分句即要点；
    **考点模式考点句（含「考试重点/必考/常考/易错」等信号词）优先入选并标 high**；
  - 未配置 Key / 调用失败 / 输出非法 → 静默降级规则引擎，断网可用、演示不崩
- **笔记实体**：`notes` 表（标题/概要/要点[重要度]/模式/引擎/来源资料引用），
  可人工编辑（改标题、增删要点、调整重要度与模式）、可按资料过滤；
  单条与全量 **Markdown 导出**（重要度以 ★/●/· 标注），数据可带走
- **多端同步**：笔记进同步快照（来源资料引用按 uuid 跨端重映射），删除留墓碑传播，
  与课程/资料/任务同一套 LWW 口径；`/api/sync/status` 计数含笔记
- **入口**：资料库每张卡片「提炼笔记」按钮（弹窗即提即存）；「AI 笔记提炼」页支持
  任意文本自由提炼（课堂笔记/讲义粘贴即用）与**识图提炼**（上传板书照片/课件截图 →
  本地 OCR 识文 → 提炼，识别原文可展开核对、切换模式用原文重新提炼不重复上传）；
  全文为空（扫描件 OCR 失败）时给出明确指引

### 4.8 学习进度预测 / 负载预警（已实现）

「复习计划生成」回答「每天学什么」，本模块回答「这样学来得及吗、会不会学爆」：

- **课程进度预测**：对每场未完成的考试/大作业（kind=exam/report 或标题含
  「考试/期末/期中/答辩/验收」，同一门课取最早一场），用与复习计划**同一套时长公式**
  （基础 × 难度 × 考点 × 掌握系数，抽到 `spacedrep.material_hours` 单源共享）计算
  剩余学时与所需节奏（剩余学时 ÷ 剩余天数），与每日学习容量对比给出
  **进度良好（≤80% 容量）/ 进度偏紧（≤容量）/ 进度预警（>容量）**；逾期 7 天内的
  考试仍参与预测并直接预警
- **顺序仿真**：每天把容量先分给最早到期的课程（剩余顺延下一门），逐日推演
  **预计完成日期**与**考试日预计掌握程度**——课程互相挤占容量时自动升级预警；
  输出逐日「预计掌握度曲线」（按资料数加权，前端 SVG 渲染，考试日标红虚线）
- **负载预警**：未来 7/14/21/30 天逐日汇总「DDL 截止（考试 2.0 / 报告 1.5 / 实验 1.2 /
  作业 1.0 权重，逾期按今天计）+ 复习计划学时 + 到期间隔复习（每份 0.5h）」，
  超过每日容量 100% / 150% 分别预警**偏满 / 超载**，并追加「连续 N 天高负载」
  「考试撞车（间隔不足 3 天）」结构化告警
- **节奏对比**：近 7 天实际复习节奏（间隔重复评分记录近似）vs 所需节奏，明显偏低即提醒；
  每日容量与预警窗口前端一键切换，参数越界 422
- 全部计算为**纯函数引擎**（`app/forecast.py`，不碰数据库），与复习计划共享公式、
  口径一致；`GET /api/forecast` 只读聚合，测试覆盖状态判定 / 顺序仿真 / 负载告警 /
  考试撞车 / 已掌握课程 / 逾期宽限 / 参数边界

### 4.9 清单 / 模版库 / 共享清单（分享链接）（已实现）

「复习清单」回答「每天学什么」，本模块补上学生高频的**通用勾选清单**场景——并让它
可以像笔记一样沉淀成模版、像链接一样发给同学：

- **通用勾选清单**：独立实体（标题/描述/课程/标签/截止日 + `items[{text, done, note}]`），
  卡片带进度环与完成态，行内加项/勾选/删项；单条可导出 Markdown（`- [x]` 勾选格式，数据可带走）
- **模版库**：
  - **内置模版（只读受保护）**：13 个学生高频模版（期末复习清单、考前冲刺清单、
    考研月度复习、四六级备考、英语期末备考、论文写作任务、课程论文/报告、实验报告、
    开学准备、奖学金申请、每日高效学习、每周学习计划、期末周作息），
    按 `key` 幂等播种——**每次启动 upsert**，模版库扩增/内容修订随版本升级自动进入老用户库中；
  - **用户自存模版**：把自己的清单「存为模版」（可改标题/分类），也可直接自建模版，
    可编辑可删除；分类固定枚举（复习备考/英语考试/论文写作/校园生活/日常学习），非法分类 422；
  - **使用流程**：选模版 → 复制生成新清单实例（勾选清零），改动绝不回流模版
- **共享清单（分享链接）**：
  - `secrets` 192bit 强随机 token；只读公开视图 `GET /api/share/{token}`（免登录、
    CORS `*`、无副作用），返回清单快照 + 过期时间 + `is_owner`（loopback 视为本人预览）；
  - **可选过期**（1 小时 ~ 1 年或永久）、**随时撤销**（立即 404）、**查看计数**；
    撤销/过期/删清单统一失效且不泄露是否存在；
  - 查看端勾选进度只存本端浏览器 localStorage——多人看同一链接互不干扰、绝不写回分享者数据；
  - **一键导入**：分享页检测本机 StudyOS → 跳转 `/#/checklists?import=<分享链接>` →
    **本机后端**用 httpx 抓取远端分享（页面链接自动归一化为 API 地址）→ 校验 →
    勾选清零、课程按名字匹配本机、归导入者所有；离线兜底 = 下载 JSON 手动导入；
    删除清单联动删除其分享链接
- **安全口径与既有体系一致**：公开接口只读；导入等写操作走本机后端、仍受
  Origin 同源校验（恶意网页无法借分享页向本机写数据）；分享视图不泄露课程 id 等内部字段

### 4.10 错题归集（错题本）（已实现）

「复习计划」回答「每天学什么」，「间隔重复」衡量资料掌握度，本模块补上学生最痛的
**错题场景**——做错的题总是散在试卷、作业和练习里，考前想重做却找不到：

- **错题实体**：`wrong_questions` 表（标题/题目原文/我的答案/正确答案与解析/错因分析 +
  来源/课程/章节/难度/标签），来源记录「哪张卷子错的」，错因留痕「当时怎么错的」；
- **自动化降成本（与资料归档同一套规则引擎）**：章节/难度留空时按「标题 + 题干 + 来源」
  自动规则抽取（`第N章` 抽取、难易词典判定），可手动修正，非法难度 422；
- **组合过滤 + 检索**：课程 × 章节（包含匹配）× 难度 × 状态（待攻克/已掌握）×
  多标签（any/all，`json_each` 精确匹配 SQL 下推，无 JSON1 内存兜底）+ 关键词
  （题干/答案/错因/来源 LIKE）；计数/排序/分页都在过滤之后（`X-Total-Count` 真实总数），
  待攻克错题永远排最前；
- **重练模式（掌握判定闭环）**：随机抽「待攻克」错题逐题自评——连续答对 2 次自动
  「已掌握」、答错 streak 清零回退「待攻克」；每题的累计重练次数/答错次数/最近自评
  全程留痕；列表卡片支持单题快速重练（先回忆再看答案）；
- **统计看板**：总数/待攻克/已掌握/掌握率 + 按课程分布，首页统计与错题本页联动；
- **导出与同步**：单条/全量 Markdown 导出（题目+答案+错因，数据可带走）；错题与重练
  记录随同步快照跨端迁移（课程引用按 uuid 重映射、删除留墓碑），`/api/sync/status`
  计数含错题

### 4.11 学习报告 / 学期统计（已实现）

「进度预测」回答「未来学不学得完」，本模块回答「这个学期学得怎么样」——把分散在
复习状态与错题本里的学习行为按**学期**聚合成一张答辩用的**数据大图**：

- **学期维度汇总**：按课程 semester 字段分组（空值/无课程归入「未分学期」），每学期
  给出课程数 / 资料数（已复习·已掌握）/ 平均掌握度 / 复习总次数 / 错题总数与攻克率 /
  任务完成率，跨学期对比表一眼看全；「全部学期」视图与单学期同一口径
- **掌握度趋势**：从间隔重复评分历史（material_reviews.history）逐周重放，每周末
  计算全学期平均掌握度（分母 = 全部资料、未复习按 0 计——诚实反映「这门课学了多少」），
  曲线随复习推进抬升
- **复习次数时间线**：逐周评分次数 + 累计（检索练习频率）；有掌握度但无历史记录的
  旧库/跨端同步状态按 last_reviewed_at 合成事件，老数据同样能进趋势图
- **错题攻克率时间线**：逐周新增/攻克错题 + 累计攻克率（攻克时刻 = 已掌握错题的
  最近自评时间），「待攻克 → 已掌握」的推进节奏一目了然
- **Markdown 报告导出**：同一份数据一键导出 .md（指标表 + 逐周时间线表），
  数据可带走、答辩材料直接引用
- 全部计算为**纯函数引擎**（`app/report.py`，不碰数据库），`GET /api/report` 只读
  聚合、`GET /api/report/md` 导出；前端三个 SVG 图（掌握度曲线 / 复习柱状 /
  攻克率折线）+ 学期对比表，学期切换一键完成；测试覆盖周桶对齐 / 趋势重放 /
  攻克率累计 / 学期分组 / 无学期兜底 / 旧数据合成事件 / 参数边界

### 4.12 AI 自测 / 抽背（已实现）

「笔记提炼」把资料变成笔记，「间隔重复」衡量资料掌握度，本模块补上学生最直接的
**自测场景**——基于笔记/资料自动出题，考考自己到底记没记住：

- **出题来源四选一**：按课程（自动取该课程笔记，无笔记时回落课程资料全文）/
  指定资料全文 / 多选笔记合并抽背 / 自由粘贴文本（课堂笔记即贴即测）；
  笔记页每张卡片一键「抽背」直达出题页
- **两种题型**：
  - **选择题**：4 选项 + 解析，服务端**自动判分**即时反馈（正确项标绿、错选标红、
    解析与出处原文可查）；
  - **问答题**：先回忆（可默写留痕）→ 显示参考答案 → **自评「记住了/没记住」**
    （与错题本重练同一自评口径，不假装 AI 判主观题）
- **双引擎出题 + 离线兜底**（与提炼/抽取同一原则）：
  - LLM 通道：严格 JSON 出题（题干/选项/答案字母/解析/参考答案要点），
    忠于原文不编造；非法输出（题型错误/答案超范围/空答案）逐题清洗丢弃，
    全非法自动回落；
  - 离线规则通道（纯函数、确定性）：选择题 = 句内关键术语挖空 +
    全文术语池做干扰项（正确项位置轮转）；问答题 = 「什么是 X」定义句模式 +
    「请回忆并补充空缺」要点回忆；**题型兜底**——素材不足时用另一题型补齐题量，
    文本再短也不会得到空试卷；
  - 未配置 Key / 断网 / 调用失败 → 静默降级规则引擎，演示不崩
- **作答全程留痕**：同一题重复作答以最后一次为准（LWW），可随时**继续/重做**；
  组统计（选择题正确率 / 问答自评通过率 / 按课程分布）与首页联动
  （`/api/stats` 含自测组数与完成组数）
- **多端同步与导出**：自测组随同步快照跨端迁移（课程/资料/笔记引用按 uuid 重映射、
  删除留墓碑）；单组/全量 Markdown 导出（题目+答案+我的作答，数据可带走）

### 4.13 番茄钟 / 专注计时（已实现，可挂到复习计划上）

「复习计划」回答「每天学什么」，本模块回答「怎么坐下来把那一块学完」——学生场景
高频刚需的番茄工作法计时，并与复习计划、间隔重复打通：

- **计时核心**：专注/短休息/长休息三阶段 + 每 N 个专注长休息轮次点；基于**结束时间戳**
  计算剩余（切后台/锁屏回来依然准确，不靠 setTimeout 累加）；标签页标题实时倒计时；
  阶段结束 WebAudio 提示音 + 可选**桌面通知**（页面切走也能看到）；常用节奏一键预设
  （经典 25/5、学习 45/5、冲刺 50/10、长跑 60/10），专注/休息时长与自动衔接均可调
- **后端持久化**：`focus_sessions` 表落库每次专注/休息（自然完成、放弃、跳过都记录），
  换浏览器/清缓存不丢——对比旧版仅存 localStorage；**旧版本地统计一键迁移合并**
  （检测到旧数据且服务端无记录时提示导入，导入后清除本地旧数据）
- **统计看板**：今日番茄数/专注分钟、**连续专注天数（streak，今天没开始则从昨天起算）**、
  累计专注、近 7 天柱状图、**按课程分布**、专注时间线（起止/时长/绑定对象/完成态，
  误记可删）；口径诚实：放弃的番茄**不计入番茄数**但时间仍计入分钟；
  番茄工作法配套「记录打断」计数（被打断就重置本个番茄）
- **可挂到复习计划上（闭环）**：
  - 专注对象三选一：自由专注 / DDL 待办任务 / **复习计划的某天复习块**（今日复习块
    置顶，可展开全部日期）；绑定复习块自动带上课程与块内资料；
  - 复习计划页每个复习块**一键「开始专注」**（`/focus?plan=ID&date=…` 直达并预选绑定），
    并展示该复习块「已专注 X 分钟（N 🍅）」投入进度；
  - 专注完成后若绑定复习块 → **就地给块内资料评分**（忘了/吃力/正常/轻松，同一套
    间隔重复 API）→ 掌握度实时更新，复习计划随之优化——「计划 → 专注 → 评分 → 计划」
    闭环；评完一键回复习页看掌握度
- **首页联动**：`/api/stats` 增加今日番茄/专注分钟/连续天数，首页番茄钟入口卡片
  显示今日进度并直达开始
- **统计引擎纯函数**（`app/focusstats.py`，不碰数据库）：今日/近 N 天/连续天数/累计/
  课程分布/复习块投入一次聚合，与复习计划「今天」同一本地日期口径；测试覆盖
  会话校验（非法模式/未来开始时间/时长边界/绑定对象 404）、聚合口径（放弃不计番茄、
  休息不计统计、连续天数、课程与复习块分组）、删除与旧统计迁移（非法日期整体拒绝、
  条数上限）

### 4.14 本地账号 · 登录保护（已实现）

回应「数据存储安全」「长期可用性」评审点中「谁能打开我的数据」的一环——单机
免登录之外，提供**可选的本机访问锁**，并把它做成一个完整、可答辩的账号体系：

- **零注册即用 + 可选保护**：登录保护默认关闭（保留零门槛体验）；注册首账号后
  一键开启，开启后除公开分享/健康检查外的全部 API 与页面都需登录（Bearer 会话
  令牌 256bit 强随机、库中只存 sha256、30 天有效 + 活跃滑动续期——每天在用的
  设备不会被用到一半踢下线）
- **密码安全**：PBKDF2-HMAC-SHA256（随机盐 + 21 万次迭代，OWASP 2025 口径），
  库里绝无明文；用户名大小写不敏感判重（数据库唯一索引兜底）；密码至少 6 位、
  不得与用户名相同；改密码即注销其它全部会话（被盗会话当场作废）
- **登录防爆破**：按「用户名 × 来源 IP」统计连续失败，超阈值指数退避锁定
  （30 秒起逐次翻倍、封顶 1 小时，429 + Retry-After）；失败恒定延迟 + 用户不存在
  也跑一次等价 PBKDF2——抹平「未知用户 vs 密码错」的耗时差，防用户名枚举；
  开放注册窗口按来源 IP 限速（防局域网批量灌账号）
- **账号即本机访问锁**：账号不进同步快照、不进完整备份——换设备各持自己的账号，
  全部账号共享同一份学习数据（家人共用一台电脑等场景）；成员账号由已登录管理员
  添加/删除
- **登录会话管理**：设置页可查看全部登录设备（最近活跃时间）、撤销任一会话、
  「一键退出其它设备」——手机/笔记本借给别人用过的痕迹一眼可见、随时收回
- **安全事件审计**：登录成败/注册/改密/开关保护/账号与会话管理全部落
  `auth_events`（用户名 + 来源 IP + 时间，只保留最近 500 条），设置页安全日志
  可查——「谁在什么时候登录过」答得上来
- **忘记密码兜底（无在线重置入口）**：应用内**故意**没有网页「找回密码」——
  任何浏览器可触达的重置都会让访问锁形同虚设；恢复走命令行工具
  `python -m app.authadmin`（reset-password / disable-protection / list-users /
  delete-user），与直接改 SQLite 等价但更安全：同一套校验与哈希、重置即注销
  全部会话、操作留审计事件；登录页给出明确指引
- **安全口径与既有体系一致**：令牌走 Authorization 头（自定义头不随跨站请求
  携带，与 Origin 同源校验双保险）；401 带 `WWW-Authenticate`；`/api/sync/*`
  兼容远端设备的 `X-Sync-Token` 通道（点对点同步不受登录会话影响）
- 测试覆盖注册/登录/登出/开关保护/改密/删号/防爆破锁定/注册限速/会话撤销/
  滑动续期/过期清理/事件审计/CLI 恢复工具全链路（`tests/test_auth.py`），
  以及**全 API 表面收口扫描**：开启登录保护后动态枚举全部 /api 路由，
  逐一验证「无令牌 401、持凭据非 401、OPTIONS 预检放行」——以后新增接口
  自动纳入检查，漏加豁免即测试红灯

## 5. 自动化能力设计（硬性要求 ②）

> 要求：至少能从文本、截图、文件名之一自动提取 DDL 时间或标签。**建议三个都做**，因为它们共用同一套抽取管线，边际成本低。

采用 **分级抽取 + 人工确认兜底** 策略：

```
文件名/文本 ──▶ 规则引擎（正则：日期、周次、课程码）──▶ 高置信直接入库
      │                    │ 低置信
      ▼                    ▼
   截图 ──▶ OCR ──▶ LLM 结构化抽取 ──▶ 置信度标注 ──▶ 低置信进入「待确认」列表
                                                          （一键确认，绝不静默写错）
```

- **时间表达归一化**：所有相对时间（下周/三天后）锚定到「当前时间 + 学期校历」解析为绝对时间戳；「第12周」需要学期起始日期配置（首次使用引导设置，写入本地）。
- **LLM 输出 Schema 化**：强制 JSON 输出（`{task_title, due_at, course, tags[], material_type, confidence}`），时间字段要求 ISO 8601，解析失败即降级为人工录入表单，**演示不崩**。
- **模型适配层**：支持云端 API（DeepSeek/OpenAI 兼容）与本地模型（Ollama）可切换——答辩现场断网也能演示离线路径。

### 6.4 数据存储安全（评审维度，重点包装）

- **本地优先**：数据在用户侧（SQLite + 文件），不上传到任何第三方云盘
- **导出即备份**：iCal/CSV/Markdown 导出天然是数据可携带的备份——「数据永远能带走」直接回应长期可用性
- **完整备份**：一键下载 zip（全部数据 + 原始附件），新设备一键恢复，换电脑零成本
- **凭据最小披露**：API Key 与同步令牌一律只回掩码；同步令牌（= 全部数据的读写权限）
  不在 `/api/sync/status`、`/api/settings` 等被动查询里明文返回，只在用户于**本机**页面
  显式点击「显示令牌」时披露（`POST /api/sync/token/reveal`，附风险提示、60 秒自动隐藏、
  服务端留披露日志）；非本机来源默认拒绝，需 `ALLOW_REMOTE_ADMIN=1` 显式放开
- 可选：AES 加密存储、删除即物理删除

### 6.5 多端同步（已实现：点对点、无云端）

- **零服务器**：两台设备都运行 StudyOS，设备 A 填设备 B 的地址 + 令牌即可一键同步，不经任何第三方
- **一致性**：每行数据带全局 `sync_uuid` + `updated_at`，删除留墓碑；合并按时间戳 **Last-Write-Wins**，两端各自修改后一轮往返收敛。**时间统一 UTC 存储**（库内 naive UTC、API/快照带 `Z` 时区、展示按设备本地时区，时间源仅为设备本地时钟——断网可用），跨时区双设备同步不再互相偏移，旧库启动时一次性自动迁移
- **引用重映射**：快照内引用一律用 uuid，导入时映射到本机自增 id（课程/资料/任务/复习计划/设置全覆盖，附件文件 base64 随传，>32MB 跳过只传文本）
- **安全**：同步接口必须携带设备令牌（可重新生成），数据只存两台设备本地
- **令牌知情同意**：配对需要明文令牌，但它等同于全部数据读写权限——因此界面默认只显示
  「掩码 + 指纹（sha256 前 8 位，可跨端核对同一令牌）」，明文需显式点击、仅限本机、60 秒自动隐藏

## 9. 风险清单与规避

| 风险 | 规避方案 |
|---|---|
| 时间表达歧义（「下周」跨月、「12.1」年份缺失） | 学期锚定 + 双确认 UI，低置信必进待确认列表 |
| OCR 质量差（截图模糊、表格） | 规则 → 文本 → OCR → LLM 分级，OCR 结果永远可编辑 |
| LLM 幻觉（抽错时间/课程） | Schema 强约束 + 置信度阈值 + 人工确认兜底，演示预设降级路径 |
| 答辩现场断网 | LLM 适配层可切本地 Ollama；规则引擎离线可用；预置 demo 数据 |
| iCal 格式错误（时区/重复） | 用成熟库生成 + UID 幂等，测试导入系统日历 |
| PDF 文本不可抽取（扫描版） | 检测无文本层时自动走 OCR |
