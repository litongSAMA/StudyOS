## 2. 隐私保护方式（技术措施，逐条可核对）

### 2.1 本地优先存储，默认不出网

- 数据落在本机 `backend/data/`：SQLite 库（`studyos.db`）+ 原始附件目录（`data/files`）。`app/config.py::Settings.data_dir` 可指向任意本地/私有路径。
- 默认**零配置可用**：未配置任何大模型 Key 时，抽取、笔记提炼、出题、语义检索全部走**内置离线规则引擎**（`backend/app/agent/`、`quizgen.py`、`semantic.py`），不产生任何网络请求。
- 语义检索默认使用内置离线 TF-IDF 向量；只有使用者显式配置 Embedding 服务后才会调用外部接口。

### 2.2 账号与凭据保护

| 措施 | 细节 | 位置 |
| --- | --- | --- |
| 密码只存哈希 | PBKDF2-HMAC-SHA256，60 万轮 + 每个账号独立随机盐；库中**绝无明文密码** | `app/auth.py::hash_password` |
| 会话令牌只存哈希 | 256 bit 强随机会话令牌，库中只存 `sha256` 摘要；30 天过期 + 活跃滑动续期 | `app/auth.py::new_session / session_user` |
| 改密即失效 | 修改密码立即作废其它会话；可查看/撤销每个登录会话、一键退出其它设备 | `POST /api/auth/password`、`/api/auth/sessions*` |
| 防用户名枚举 | 账号不存在时同样执行等价 PBKDF2 计算 + 恒定延迟；密码不得与用户名相同、长度 6~128 | `app/auth.py::validate_password` |
| 登录防爆破 | 按「用户名 × 来源 IP」连续失败指数退避（30 秒起逐次翻倍、封顶 1 小时，`429 + Retry-After`），成功即清零 | `app/auth.py`、`auth_attempts` 表 |
| 注册限速 | 开放注册按来源 IP 限速，防局域网批量灌账号 | `POST /api/auth/register` |
| 安全审计 | 登录成败/注册/改密/开关保护/账号与会话管理/命令行找回全部落 `auth_events`（用户名 + 来源 IP + 时间，仅保留最近 500 条） | `GET /api/auth/events` |
| 忘记密码 | **应用内故意不提供在线重置入口**（避免成为绕过口子），只能在本机命令行恢复：`python -m app.authadmin reset-password <用户名>`（重置即注销全部会话并留审计） | `app/authadmin.py` |

### 2.3 密钥与令牌脱敏

- 大模型 API Key、Embedding Key、同步令牌在 `GET /api/settings`、`GET /api/sync/status` 中**一律只返回掩码**（形如 `sk-••••••abcd`）与指纹（sha256 前 8 位），任何接口都不回显明文（`app/config.py::mask_key`，测试 `test_settings_masks_secrets`）。
- 明文同步令牌**只能在本机页面显式点击查看**（`POST /api/sync/token/reveal`），服务端留披露日志、前端 60 秒后自动隐藏并给出风险提示；**非本机来源默认拒绝披露**（需显式 `ALLOW_REMOTE_ADMIN=1` 才放行）。
- 通用设置接口**拒写**系统级配置（同步令牌/远端地址/AI 密钥，403），防止借通用入口篡改凭据。

### 2.4 分享链接：只读、可撤销、不回流本人数据

- 分享 token 为 192 bit 强随机（`secrets`）；公开视图 `GET /api/share/{token}` **仅 GET、无副作用**，只返回清单快照。
- 支持设置过期时间（1~8760 小时或永久）、随时撤销、查看计数；撤销/过期/删除清单 → 立即失效（404/410）。
- 查看端的勾选进度**只保存在查看者自己的浏览器**，绝不写回分享者的数据。
- 分享内容不含账号信息、不含附件正文以外的隐私字段，由分享者自行决定分享哪一份清单。

### 2.5 用户对自己数据的完全控制权

- **随时导出带走**：DDL/复习清单/资料目录 → iCal · CSV · Markdown（增量导出可选）；完整备份 zip 一键导出。
- **随时删除**：单条/批量删除资料（附件、全文索引、语义向量、复习状态一并清理）、清空导出历史、删除账号（`python -m app.authadmin delete-user`）。
- **不上云、不锁定**：不依赖任何云服务即可长期使用；即使服务停止，导出的 iCal/CSV/Markdown 仍可读。

## 3. 是否使用未授权敏感数据（明确否定）

**结论：未使用任何未授权的敏感数据。** 逐类说明：

| 敏感信息类型 | 是否采集 | 说明 |
| --- | --- | --- |
| 身份证号 / 学号 / 姓名实名信息 | ❌ 否 | 账号仅需一个**自定义用户名**（无需邮箱、手机号、学号），无实名要求 |
| 手机号 / 邮箱 / 验证码 | ❌ 否 | 无任何短信/邮件验证通道；未配置的服务商接口明确返回不可用，**不伪造验证结果** |
| 精确定位 / 轨迹 | ❌ 否 | 不请求定位权限，无地图/签到功能 |
| 通讯录 / 通话记录 / 短信 | ❌ 否 | 不请求相关权限 |
| 相册 / 摄像头 / 麦克风 | ❌ 否 | 仅在用户**主动选择文件**时读取该文件；不扫描相册、不后台采集、不录音 |
| 生物特征（人脸/指纹/声纹） | ❌ 否 | 无相关功能 |
| 健康 / 金融 / 征信 | ❌ 否 | 无相关功能 |
| 设备唯一标识 / 广告 ID | ❌ 否 | 无埋点、无广告 SDK、无第三方统计，不生成设备指纹 |
| 他人数据（同学/老师/群聊记录） | ❌ 否 | 使用者只能导入**自己**的资料；系统不提供导入他人数据的通道 |
| 未公开的教务系统接口 / 破解数据 | ❌ 否 | 只解析使用者**自己导出**到本地的文件（Excel/CSV/PDF/网页打印页/截图） |

**唯一的"出网"场景及其边界（主动、可见、最小）**：使用者若在「设置 → AI 模型接入」中自行填写 Key 并启用，则以下内容会发送到**使用者自己选择的服务商**：
1. 待提炼/抽取的**文本内容**（资料正文片段或用户粘贴文本）；
2. 待出题/待判分的题目素材；
3. 语义检索所需的文本片段（用于 embedding）。

边界保证：① 默认不开启、不配置则不发出任何请求；② 服务商地址与模型由使用者显式选择（DeepSeek/OpenAI/硅基流动/Kimi/智谱/本地 Ollama/自定义），也可完全指向本地 Ollama 实现**零出网**；③ 不发送账号、密码、密钥、同步令牌、原始附件文件本身（仅文本）；④ 连通性测试由使用者点击触发；⑤ 出站请求统一**拒绝链接本地/云元数据地址**（防 SSRF，见 `sync.py` 出站校验）；⑥ 界面与 `engine` 字段**如实标注**本次结果来自 LLM 还是离线引擎，不谎称使用了远程模型。

## 4. 数据脱敏处理

| 场景 | 脱敏方式 | 位置 |
| --- | --- | --- |
| 界面/接口回显密钥与令牌 | 只回掩码 + 指纹，明文仅本机显式披露 | `mask_key`、`/api/sync/status`、`/api/settings` |
| 同步/备份中的账号凭据 | 账号与密码哈希**不进同步快照、不进完整备份**（避免对端无账号却被同步过去的开关锁死） | `app/sync.py` |
| 登录保护开关 | 存 `app_settings`，同样**不同步、不备份** | 同上 |
| 日志 | 后端日志只记录请求路径与状态，不落密码、密钥、令牌明文；一次性口令/令牌不在日志中出现 | `logs/backend.*.log` |
| 演示与测试数据 | 测试用临时库 + 合成数据；`scripts/seed.py` 全部虚构；测试用例中的姓名/课程/成绩均为构造值 | `backend/tests/conftest.py` |
| 对外分享 | 分享快照不含账号信息与其它清单；查看端进度不回写 | `/api/share/{token}` |
| 审计信息 | `auth_events` 只留用户名与来源 IP（不含密码尝试内容），上限 500 条自动裁剪 | `app/auth.py::event` |

> **说明（如实）**：本系统不对使用者上传的**学习资料正文**做自动脱敏——因为资料由使用者本人所有并仅存本机，自动改写反而会破坏原始内容。
> 若使用者上传的资料里含他人敏感信息（如班级成绩单），责任在导入者，界面与文档均提示"请勿上传含他人隐私的材料"。

## 5. 权限控制

| 层级 | 措施 | 位置 |
| --- | --- | --- |
| 访问入口 | **登录保护开关**（默认关闭以保留"零注册即用"体验）：开启后除 `/api/health`、`/api/share/*`、`/api/auth/*` 外全部 API 与页面需登录 | 全局中间件 `app/main.py` + `app/auth.py::authorize_request` |
| 会话 | `Authorization: Bearer` 会话令牌（自定义头不随跨站请求携带）；改密/登出即时失效；会话可查看可撤销 | `/api/auth/sessions*` |
| 账号边界 | 全部账号共享**同一份本机学习数据**——登录是"本机访问锁"，不做多租户隔离（能力与边界均如实标注，不夸大） | `docs/AGENT_CORE.md` |
| 跨站防护 | 所有**写操作**校验请求 `Origin` 与页面同源 → 恶意网页无法借浏览器偷偷调本机接口（CSRF 防护） | `test_health_stats.py::test_csrf_origin_guard` |
| 本机限定 | 明文同步令牌披露、`/api/sync/now` 主动同步等敏感动作**只允许本机（loopback）来源**，局域网设备默认被拒 | `POST /api/sync/token/reveal`、`ALLOW_REMOTE_ADMIN` |
| 设备间权限 | 点对点同步用**设备令牌**（`X-Sync-Token`）鉴权，不经过任何云端；令牌可随时重新生成使其立即失效 | `/api/sync/*` |
| 文件系统 | 附件只允许落在 `data/files`（防任意路径读写/删除）；上传/备份恢复限制大小 | `app/filestore.py` |
| 内置资源 | 内置清单模版**只读**（修改/删除返回 403），用户自建模版可改可删 | `/api/checklist-templates` |
| 分享 | 公开只读视图仅 GET、无副作用、可过期可撤销 | `/api/share/{token}` |

## 6. 数据收集范围（最小必要）

**收集的字段（全部服务于"资料—任务—复习"闭环，无一项用于画像或营销）**：

| 类别 | 字段 | 必要性 |
| --- | --- | --- |
| 账号 | 用户名、密码哈希、创建/最近登录时间 | 仅用于本机访问控制；**不要**邮箱/手机号/学号 |
| 课程 | 课程名、教师、地点、上课时段、周次、学期、配色 | 课表与复习计划的基础 |
| 资料 | 标题、正文/抽取文本、原始文件、课程、章节、难度、类型、标签、考试重点标记、入库时间 | 检索、提炼、复习分配的基础 |
| 任务/DDL | 标题、截止时间、提醒提前量、完成状态 | 提醒与倒排计划的基础 |
| 复习 | 掌握度、间隔、下次到期、评分历史 | 间隔重复调度的基础 |
| 学习行为 | 专注/番茄记录（时长、阶段、绑定对象）、自测作答、错题重练记录 | 统计与掌握判定的基础；**仅本机** |
| 配置 | AI 服务商/模型/密钥（掩码回显）、学期锚点、同步令牌（掩码） | 功能配置 |

**明确不收集**：设备标识、IP 地理位置、浏览历史、剪贴板内容（仅在用户主动 Ctrl+V 到上传区时读取粘贴内容）、
使用时长埋点、崩溃遥测、任何用于广告或用户画像的数据。**没有第三方统计/广告/推送 SDK**，
唯一的推送通道是浏览器原生 Web Push（VAPID，密钥本机生成并持久化于 `data/vapid_keys.json`）。

## 7. 引用来源可追溯性

### 7.1 系统内可追溯（每条产出都能回到原始资料）

| 追溯关系 | 实现 |
| --- | --- |
| 资料 → 原始文件 | 保留原始文件名、扩展名、实际嗅探格式、入库时间、`stored_path`、抽取正文（可展开"抽取原文"核对） |
| 笔记 → 资料 | 笔记挂资料引用；提炼回包带 `source_text` 与 `format_label`，可核对、修正后重提炼 |
| 自测题 → 笔记/资料 | 每题带 `source` 字段；生成时记录来源（课程笔记/指定资料/多选笔记/自由文本）；选择题带解析 |
| 错题 → 课程/章节/来源 | 错题带课程、章节、难度、来源（如"2026 期中考试"）、标签与重练记录 |
| 复习计划 → DDL/资料 | 每个复习块给出对应资料的掌握度与到期标记，可点开原资料 |
| 导出文件 → 来源与时间 | iCal（稳定 UID + VALARM + DESCRIPTION 含元数据）、CSV（UTF-8 BOM）、Markdown 均含标题与时间信息；`export_records` 记录每次导出的时间窗口与条数 |
| 同步/备份 → 跨端一致 | 每行数据带全局 `sync_uuid` 与 `updated_at`，删除留墓碑，可解释"这条数据从哪来、何时改过" |

### 7.2 外部引用可追溯（本项目引用的第三方内容）

| 引用对象 | 来源与许可 | 说明 |
| --- | --- | --- |
| Python / Node 依赖 | 见 `backend/requirements.txt`（**逐项 `==` 锁定版本**）与 `requirements.lock`（含全部传递依赖）；`web/package.json`、`mobile/package.json` | 均为开源软件（MIT/Apache-2.0/BSD 等），仅作库使用，未修改其许可声明 |
| 中文分词 | `jieba==0.42.1`（MIT） | 本地分词，用于 FTS5 索引与关键词抽取 |
| OCR | `rapidocr-onnxruntime==1.2.3`（Apache-2.0，可选依赖） | 本地离线 OCR 模型，不联网 |
| PDF 解析 | `pymupdf==1.28.2`（AGPL-3.0 / 商业双许可，官方 PyPI 发布） | 用于 PDF 文本与表格抽取；**如对外分发需自行确认许可适用**（本项目为竞赛作品、非商业分发，并保留原库许可声明） |
