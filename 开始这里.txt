二、方式 A：免安装包（推荐，不装 Python / Node.js）
--------------------------------------------------------------------------------
1. 解压 release/StudyOS-Windows-x64.zip（会得到 StudyOS-Windows-x64/ 目录）
2. 双击其中的 StudyOS/StudyOS.exe
3. 浏览器打开窗口里显示的地址（默认 http://127.0.0.1:8800）

   注意 1：端口 8800 被占用时程序会自动改用 8801–8899，
           请以启动窗口里打印的地址为准，不要固定用 8800。
   注意 2：解压后请完整保留 _internal 目录，不能只拷贝 StudyOS.exe。
   注意 3：本包内置的 使用说明.txt 中写明：该 Windows 包【尚未在 Windows 实机
           验收】。评审如遇启动异常，请改用下面的方式 B（源码路线）——源码
           路线已在本机完整实测，功能一致。
   自检：双击 StudyOS/运行自检.cmd，在临时目录跑 40 项检查，不改动学习数据。


三、方式 B：源码启动（已实测，功能最完整）
--------------------------------------------------------------------------------
Windows：双击 scripts\start.bat（自动建 venv、装依赖、起服务、开浏览器）
macOS / Linux：
    ./scripts/start.sh -d      # 后台常驻
    ./scripts/stop.sh          # 停止

访问 http://127.0.0.1:8800 ，接口文档 http://127.0.0.1:8800/docs 。
默认【无需登录、无需注册、无需任何 API Key】；不联网也能演示完整流程
（内置离线引擎）。需要联网 AI 时在界面「设置」里填自己的 Key。

灌入演示数据（合成数据，可重复执行）：
    cd backend
    .venv\Scripts\python.exe scripts\seed.py --reset      # Windows
    .venv/bin/python scripts/seed.py --reset                 # macOS / Linux


四、完整性校验
--------------------------------------------------------------------------------
- release/StudyOS-Windows-x64.zip 的校验值见 release/SHA256SUMS.txt：
      在 release/ 目录执行  sha256sum -c SHA256SUMS.txt
      macOS: shasum -a 256 -c SHA256SUMS.txt
      期望输出：StudyOS-Windows-x64.zip: OK
- 本目录全部文件的 SHA256 见 SHA256SUMS.txt（本文件所在目录）：
      sha256sum -c SHA256SUMS.txt
